# 💓 Nexus Worker Heartbeat
> **The 6-Step Execution Loop**

## 🔄 The Cycle

### 1. Synchronize (Context)
- [ ] Read `SOUL.md` and `AGENTS.md`.
- [ ] Read the last 3 entries in `PROJECT-INVENTORY.md`.

### 2. Intake (Tasks)
- [ ] Check `memory/tasks.json` or manager's directive.
- [ ] Identify P0 priorities.

### 3. Execute (Action)
- [ ] Implement requested feature/task.
- [ ] Follow **Tool Mandates** in `AGENTS.md`.

### 4. Self-Check (The Wall)
- [ ] **MANDATORY**: Does the deliverable match the DoD exactly?
- [ ] Have I removed all placeholders?
- [ ] Have I tested the code/content in a "live" context?
- [ ] **Role-Specific Check**:
    - *Engineering*: Does it pass linting? No errors in console?
    - *Content*: Is the tone consistent with the brand?

### 5. Report (Communication)
- [ ] Update `memory/reports.md` with current status and any blockers.
- [ ] Notify manager of completion.

### 6. Hibernate
- [ ] Save state to `memory/state.json`.
- [ ] Exit.
