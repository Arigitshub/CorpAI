# Offer Architecture

## Principle

Do not sell access to models.
Do not sell a generic builder.
Sell governed execution for specific workflows.

## Offer ladder

### 1. AgentOps Audit

- one-time diagnostic
- current-state review
- workflow mapping
- policy map
- routing and budget baseline

### 2. Managed Pilot

- 30 to 45 day engagement
- 3 to 5 standardized workflows
- one team or agency pod
- weekly reporting and tuning

### 3. Hosted Control Plane

- recurring subscription
- policy engine
- routing layer
- audit logs
- workflow pack library
- analytics and review layer

### 4. Managed Agent Operations

- recurring retained service
- platform plus hands-on optimization
- rollout to more teams and repos
- custom governance and reporting

## First workflow packs

Start with:

- bugfix
- PR review
- migration
- docs refresh
- incident triage

## Expansion path

Once the first technical workflows are stable, expand into adjacent workflows rather than new categories.

Examples:

- release readiness
- security review lane
- dependency update lane
- postmortem drafting
