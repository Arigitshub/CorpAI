# CorpAI Workspace Layout

## Canonical root

Use:

- `D:\CorpAI`

as the single workspace root for CorpAI-related work.

## Primary folders

- `corpai-portal` - marketing and product site
- `corpai-cli` - main CLI repo inside the workspace
- `corpai-platform` - platform app now consolidated into the workspace
- `corpai-playbook` - playbook and company operating templates
- `paperclip-company-playbook` - active in-workspace paperclip playbook copy
- `docs` - current product, monetization, and execution planning docs

## Imported duplicates

The folder:

- `workspace-imports`

contains top-level repo copies that were previously saved elsewhere on `D:\` and then consolidated into this workspace without overwriting the active in-place copies.

Current imports:

- `workspace-imports/corpai-cli-root-copy`
- `workspace-imports/paperclip-company-playbook-root-copy`

These are preserved references, not the main working copies.

## Rule for future work

When continuing CorpAI, start from `D:\CorpAI` and prefer the in-workspace folders before touching anything under `workspace-imports`.
