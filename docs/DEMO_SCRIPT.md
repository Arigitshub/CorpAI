# Demo Script

## Goal

Show one governed coding-agent workflow from trigger to reporting in under 10 minutes.

## Demo setup

Use one repository and one standard workflow pack.

Recommended demo workflow:

- PR review lane

## Demo sequence

### 1. Show the problem

Explain that engineers already use coding agents, but the team lacks:

- policy
- routing visibility
- approval checkpoints
- spend reporting

### 2. Trigger the workflow

Show an engineer starting a review flow from a supported CLI or repo action.

### 3. Show policy load

Show that CorpAI attaches:

- workflow template
- repo context
- provider rules
- approval class
- budget guardrails

### 4. Show runtime routing

Show the step being routed to the selected backend.

Examples:

- Codex CLI for repo and shell actions
- Gemini CLI for comparison run
- OpenRouter for fallback or classification

### 5. Show review checkpoint

Pause on a protected action.
Show human review and explicit approval.

### 6. Show reporting

Show:

- run log
- runtime used
- fallback events
- review status
- estimated spend
- workflow outcome

## Close

Explain the pilot offer:

- we standardize 3 to 5 workflows like this
- we govern usage across the team
- we report outcomes weekly
