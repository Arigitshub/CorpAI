# Category Brief

## Category

CorpAI should define its category as:

- `Agent Operations Control Plane`

Alternative acceptable phrasing:

- `AI Agent Control Plane`
- `Control Plane for Agentic Developer Workflows`

## What the category means

CorpAI sits above agent runtimes such as `Codex CLI`, `Gemini CLI`, `Claude Code`, `OpenRouter`, and direct provider APIs.

The product is responsible for:

- workflow selection
- runtime routing
- policy enforcement
- approval checkpoints
- audit logs
- reporting and spend visibility

## What CorpAI is not

Do not define the category as:

- coding agent
- LLM wrapper
- autonomous corporation
- agent marketplace
- protocol-first AI org standard

Those may describe implementation details or legacy repo history, but they are not the sellable front-door category.

## Buyer pain the category solves

Teams already use agents.
The problem is that usage becomes:

- inconsistent
- hard to govern
- hard to review
- hard to price internally
- hard to connect to business outcomes

CorpAI solves that by turning ad hoc agent usage into a managed operating layer.

## Category rule

Every public-facing page should answer:

1. which workflows CorpAI governs
2. which runtimes it sits above
3. what approvals still require humans
4. what operational number improves
