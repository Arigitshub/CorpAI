# ROI Model

## Goal

Give buyers a simple way to justify the pilot and recurring subscription.

## Core ROI inputs

- monthly workflow volume
- average manual minutes per run
- loaded hourly cost of the reviewing human
- automation rate
- approval rate
- cycle-time improvement
- provider spend
- CorpAI subscription fee

## Core outputs

- hours saved per month
- labor dollars redirected per month
- net automation value after model spend
- cycle-time reduction
- payback period

## Phase-one framing

Do not promise labor elimination.
Frame ROI as:

- faster throughput
- reduced coordination cost
- standardized review quality
- spend visibility
- manager time recovered

## Minimum weekly proof

Each pilot review should show:

- total runs
- completed runs
- approved runs
- escalated runs
- estimated time saved
- estimated model spend
- net value trend
