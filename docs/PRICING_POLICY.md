# Pricing Policy

## Pricing rule

Do not use seat pricing as the primary model.

Price using a combination of:

- workflow scope
- managed workflow count
- active repository count
- run volume
- approval complexity
- service intensity
- included usage budget

## Initial price bands

### AgentOps Audit

- `$2.5k-$7.5k` one-time

### Managed Pilot

- `$4k-$7k/mo`

### Hosted Control Plane

- `$8k-$15k/mo`

### Enterprise BYOK

- `$2k-$6k/mo` platform fee plus services

## Commercial protections

- no free pilots
- no unlimited usage
- no hidden overages
- no custom work without scope boundaries
- no discounting implementation to zero

## Discount policy

Discount only for:

- annual prepay
- reduced support scope
- public case study rights

## Internal margin rule

Every account should be reviewed weekly for:

- model spend
- labor hours
- gross margin
- overage capture

If pricing cannot be explained in one paragraph and billed clearly in Stripe, it is too complex.
