# Metrics Definition

## Revenue metrics

- `new_mrr`
- `expansion_mrr`
- `churned_mrr`
- `gross_margin_by_account`
- `provider_spend_pct_of_revenue`

## Delivery metrics

- `workflow_run_volume`
- `automation_rate`
- `approval_rate`
- `escalation_rate`
- `fallback_rate`
- `workflow_success_rate`

## Buyer proof metrics

- `time_saved_hours`
- `cycle_time_improvement`
- `review_time_reduction`
- `weekly_proof_sent_on_time`

## Definition rule

Every dashboard metric should map to one formula and one operational meaning.
If a metric cannot be explained to a buyer in one sentence, it should not be on the default scorecard.
