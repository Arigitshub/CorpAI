# Workflow Pack Spec

## Purpose

Define the shape of the first workflow pack for CorpAI AgentOps.

## Phase-one pack

The first pack should include:

- bugfix
- PR review
- migration
- docs refresh
- incident triage

## Workflow pack components

Each workflow should define:

- trigger
- required context
- preferred runtime
- fallback runtime
- approval class
- expected artifacts
- success criteria
- metrics emitted

## Phase-one rule

Do not create broad workflow packs for every department yet.
Keep the first pack focused on coding-agent execution for technical teams already using CLI-based agents.
